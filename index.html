THE BIG IDEA

Readable, but still precise.

Englishmen is inspired by English, but it is not a chatbot guessing what you mean. It has clear rules, a lexer and parser, and a virtual machine that runs your programs.

$- Your first Englishmen program -$ say("Hello, world!")
Think of it like this: you write instructions in Englishmen syntax, save them in a .em file, and run that file with the em command.

LESSON 01 · THE FIRST LINE

Say hello to Englishmen

A program is a set of instructions. Let's start with one instruction: display a message.

Your first programSave as hello.em
say("Hello, world!")

say() is a built-in command that displays information. The text goes inside quotation marks. Parentheses hold the value being passed to the command.

Remember: Text values are called strings. A string starts and ends with quotation marks.

Run it on your computer

em hello.em

The em command runs your .em source file. You need to install Englishmen first; see the setup guide in the project README.

LESSON 02 · KEEPING INFORMATION

Variables are named boxes

A variable stores a value so you can use it later. In Englishmen, assignment creates the variable — no let or var keyword needed.

age = 18 name = "Alex" active = true say(name) say(age)

The = sign assigns the value on the right to the name on the left. You can update a variable by assigning it a new value.

score = 10 score = score + 5 say(score) $- displays 15 -$
Three common value types: numbers like 18, strings like "Alex", and booleans: true or false.

Quick check

What value does this create? score = 42

LESSON 03 · GROUPING VALUES

Lists, objects & properties

Use arrays for ordered lists and objects to group related information under named properties.

Arrays

colours = ["blue", "green", "orange"] say(colours[0]) $- blue -$ colours.add("purple") say(colours.length())

Array positions start at zero, so colours[0] means the first item.

Objects

person = { name: "Alex", age: 18, active: true } say(person.name) person.age = 19

Use a dot to access or update a property, such as person.name.

An array is like a numbered shelf. An object is like a labelled folder where each piece of information has a name.

LESSON 04 · CHOOSING A PATH

Make decisions with if

An if statement runs code only when its condition is true. Add else for the other path.

temperature = 26 if temperature > 30 say("It's hot!") else if temperature > 20 say("It's pleasant.") else say("Bring a jacket.") end

Comparison operators include == (equal), != (not equal), >, <, >= and <=.

Boolean logic: combine conditions with and and or, or reverse one with not.
if age >= 13 and age < 20 say("Teenager") end

Quick check

If points = 8, which branch runs?

if points > 5 say("A") else say("B") end
LESSON 05 · REUSABLE INSTRUCTIONS

Build your own functions

A function is a named block of code. Define it once, then call it whenever you need it.

function greet(name) say("Hello, " + name) end greet("Mira") greet("Sam")

The name inside the parentheses is a parameter. Each time you call the function, you provide an argument for it.

Return a result

function add(a, b) return a + b end total = add(10, 20) say(total)
Use say() to display something. Use return when a function should give a value back to the code that called it.

LESSON 06 · REPEAT WORK

Loops save you from copy-paste

Use a loop when you want to repeat an instruction or work through every item in a collection.

Repeat a set number of times

repeat 3 say("Keep going!") end

Visit each item in an array

friends = ["Mira", "Sam", "Jo"] for friend in friends say(friend) end

The for loop gives the variable friend each item in the array, one at a time.

Trace it: For the friends example, the loop runs three times — once for Mira, once for Sam, and once for Jo.

LESSON 07 · BUILT-IN TOOLS

Use standard libraries

Libraries group useful features so you don't have to build everything yourself. Import one, then use its functions.

import math import time say(math.sqrt(25)) say(math.pow(2, 8)) say(time.year())

math

Calculations and constants.

sqrt · abs · floor · ceil · round · pow · min · max · pi · e

time

Current date and time helpers.

now · sleep · year · month · day · hour · minute · second

qrc

Create a QR code image.

qrc.make(text, path)

cowsay

Print a message with an ASCII cow.

cowsay.say(message)
These modules ship with the Englishmen runtime. You don't need to install separate Python or Node packages for them.
