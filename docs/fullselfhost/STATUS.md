# Round 2 status: full self-hosting pipeline

The second round closes the three gaps left by the bootstrap front end. All
six work items landed on `selfhost-base` as PRs #30–#35, cross-reviewed and
merged sequentially.

| Layer | Pure-Englishmen implementation | Native reference |
| --- | --- | --- |
| Lex / parse / AST JSON | `selfhost/compiler.enm` | `selfhost/emit.enm` |
| AST → `emb` IR | `selfhost/codegen_ir.enm` (`cgCodegen`) | `src/compiler.rs` |
| IR → bytes | `selfhost/ir_encode.enm` (`ieEncode`) | `emb.encode` / `bytecode::serialize` |
| Byte buffers | `selfhost/lib_bytes.enm` (`bt*`) | `bytes` module |
| `.emc` manifests | `selfhost/lib_project.enm` (`pj*`) | `project` module |

| Runtime / builtins | `selfhost/vm_runtime.enm` (`vmRunWithRuntime`) | `src/runtime.rs` |

## Combined entry point

`selfhost/full.enm` inlines the seven self-contained `.enm` pieces (self-test
and CLI tails removed) and adds a driver. It reads one source file and prints
one JSON line with the AST statement count, IR instruction count, encoded byte
count, and the output array produced by the self-hosted runtime:

```sh
em run selfhost/full.enm examples/objects.enm
```

Verified to produce output identical to `em run <example>` for
`hello.enm`, `conditions.enm`, `arrays.enm`, `example.enm`, `objects.enm`, and
`objects-api.enm`. `cargo test --all-targets` passes with all round-2 parity
tests enabled.

## What is still native

- A Rust-built `em` executable is still needed to *run* any `.enm` script,
  including `full.enm`. Self-hosting the toolchain is not the same as booting
  it without a host.
- Source programs that `import` a native module (`string`, `fs`, `json`,
  `emb`, …) cannot yet run through the self-hosted VM: `Import` deliberately
  fails. The native module implementations in this repository are used only
  as test oracles.
- `ieEncode` returns a byte array. `fs.write` is UTF-8-only, so writing an
  arbitrary binary `.emb` file still needs a native host call.
- Englishmen cannot observe NaN sign or payload, so non-canonical NaNs are
  canonicalized to positive quiet NaN.
- Some runtime details are not reproduced: source spans and suggestion hints
  in errors, the 512-frame depth limit, exact arity validation messages, and
  host intrinsics for delegated globals.
- Local `.enm` imports do not exist, so the combined file is generated by
  concatenation rather than by an import graph.

## Language subset covered

Literals, `say`, variable define/get/assign (including compound and postfix),
unary and binary operators, short-circuit `and`/`or`/`??`, blocks,
`if`/`else`, `while`/`repeat`/`for`, `break`/`continue`, function declarations
and calls, closures, ternaries, arrays, and object literals and property/index
access. Unsupported AST nodes raise explicit errors instead of emitting bad
bytecode.
